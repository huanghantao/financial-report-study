# 数据层说明（写作前必读）

本目录是整套教程的**事实底座**。教程里出现的每一个真实公司数字，都必须能在这里或
年报原文里找到出处。**没有出处 = 不许写。**

---

## 0. 数据来源与法律说明

- **来源**：全部年报均为上市公司按监管要求公开发布的年度报告，
  A 股下载自**巨潮资讯网**（<http://www.cninfo.com.cn>），
  港股下载自**港交所披露易**（<https://www.hkexnews.hk>）。
- **著作权**：年报原文的著作权归各上市公司所有，**本仓库不收录原文**，
  只保留从原文核实过的数值（本目录的 JSON）与页码索引。
- **可核对性**：每个 JSON 的 `_meta.statement_pages` 记录了每个数据点来自哪一页，
  你可以下载同一份年报逐项复核。
- **时效性**：数据均为 2024 年度（少数标注为 2023 年对比数），不会随行情变化。

## 3. 从 raw 里提取数字的四步法

### 第 1 步：找表
A 股搜 `合并资产负债表` / `合并利润表` / `合并现金流量表`；港股搜 `綜合財務狀況表` /
`綜合損益表` / `綜合現金流量表`。**注意跳过目录页**（目录页也会出现这些词）。

### 第 2 步：认单位
- A 股：表头写 `单位:元`，也有写 `单位:千元` 的（少见）。**先看表头再抄数。**
- 港股：表头几乎都是 `RMB'000 人民幣千元`，抄进 JSON 前 **×1000**。

### 第 3 步：修 OCR 打散的数字
raw 是 PDF 转文本，数字经常被空格/逗号切碎：

| raw 里看到 | 真实含义 |
|---|---|
| `115, 393, 310, 976, 69` | 115,393,310,976.69（最后一段 2 位是小数） |
| `8, 452, 859, 993. 18` | 8,452,859,993.18 |
| `$-18.94$` | −18.94（LaTeX 包裹的负数） |
| `(53,584,334)` | −53,584,334（港股括号表示负数） |
| `1, 227, 261, 714. 62` | 1,227,261,714.62 |

修复口诀：**去掉所有空格 → 若最后一段是 2 位数字且前面是逗号，把最后一个逗号改成小数点。**

### 第 4 步：交叉验算（必须做）
- 资产总计 = 负债合计 + 所有者权益合计；
- 营业总收入 − 营业总成本 + 其他收益 … = 营业利润（差一项就回去找）；
- 归母净利润 + 少数股东损益 = 净利润；
- 期初现金 + 净增加额 = 期末现金。

**四个等式里任何一个对不上，说明你抄错了，回去重抄。**

## 4. 数字引用规范（正文里怎么写）

1. 正文金额统一换算成**亿元**，保留 1~2 位小数：
   - 115,393,310,976.69 元 → **1,153.93 亿元**（或写「约 1,154 亿元」）
   - 8,452,859,993.18 元 → **84.53 亿元**（或「约 84.5 亿元」）
2. 第一次出现时给出原值与页码：`营业收入 1,153.93 亿元（伊利 2024 年报，page_091.md）`。
3. 每个含真实数字的二级小节，在末尾单独一行写机器可查的出处注释：

   ```markdown
   <!-- src: 伊利股份2024年报/page_091.md -->
   ```

   一行可以写多个，用空格分隔：`<!-- src: 伊利股份2024年报/page_087.md 伊利股份2024年报/page_088.md -->`
4. **示意图的数字必须标注「示意数字」**，且不得与真实公司数据混在同一张表里。

## 5. 常用换算

| 原始 | 换算 |
|---|---|
| 元 → 亿元 | ÷ 100,000,000 |
| 千元 → 亿元 | ÷ 100,000 |
| 万元 → 亿元 | ÷ 10,000 |
| 百分比 | 小数 × 100，保留 1 位小数 |
| 倍数 | 保留 1 位小数（如 2.6 倍） |

## 6. 常见坑

- **单位陷阱**：把港股「千元」当「元」，所有数字大 1000 倍。
- **口径陷阱**：`营业总收入` ≠ `营业收入`（伊利前者含利息收入 3.86 亿）；`净利润` ≠ `归母净利润`（差少数股东损益）。
- **年度陷阱**：A 股年报同时列 2024 和 2023 两列，抄错列。
- **合并 vs 母公司**：教程一律用**合并报表**，不要抄母公司报表（母公司表在合并表后面几页）。
- **四舍五入**：中间计算不要提前四舍五入，最后一步再round。
