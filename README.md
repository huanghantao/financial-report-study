# 📊 读懂财报：十周从零到独立分析一家公司

> 一套面向**从没打开过年报的读者**的中文教程。从"股票到底是什么"讲起，
> 十周后你能独立读完一家公司的年报、判断生意好坏、识别主要风险，并给出一个估值区间。
>
> **主线公司：伊利股份（600887.SH）2024 年报。** 50 章里它反复出现，
> 你会像熟悉一个老朋友一样熟悉这家卖牛奶的公司。
>
> **适合谁：** 没学过会计、没买过股票、数学只会百分比，但想把投资这件事认真搞懂的人。
>
> **承诺：** 每个概念都从 0 讲透；不需要先修任何课程；不需要会写代码。
>
> **全部数字取自真实年报原文**，每一个关键数字都能追到原文页码（例如 `伊利股份2024年报/page_091.md`）。

## ⚠️ 开始之前

**这是一套教学教程，不是投资建议。** 它教你怎么读报表，不告诉你该买哪只股票。
书中所有对伊利的判断都基于 2024 年年报的公开数据，不构成任何买卖建议。

### 数据从哪来

本教程用到的年报，全部是上市公司按监管要求**公开发布**的年度报告，
从以下两个官方渠道下载后转成文本：

- **A 股**：巨潮资讯网（<http://www.cninfo.com.cn>）
- **港股**：港交所披露易（<https://www.hkexnews.hk>）

年报的著作权属于各上市公司。因此**本仓库不收录年报原文**，只保存三样东西：

1. 从原文核实过的数据（`data/*.json`）；
2. 指向原文页码的出处标记（`<!-- src: 公司名/page_NNN.md -->`）；
3. 教程正文（重写与解读，非原文转录）。

正文里出现的 `page_091.md` 这类编号，指的是**年报 PDF 转文本后的第 91 页**，
你可以自己下载对应年报核对。

### 想校验出处？

把年报文本按 `<公司名>/page_NNN.md` 的结构放好，然后：

```bash
export RAW_DIR=/你的/年报目录
python3 scripts/verify_course.py
```

不设置 `RAW_DIR` 时，页码校验会自动跳过，其余检查照常运行。

## 🤔 这套课和你自己翻年报有什么区别

年报有 270 页，第一次打开的人会被三种东西劝退：看不懂的术语、找不到的表格、不知道哪一行重要。
这套课替你做了四件事：

- **给地图**：第 1 周先教你"270 页怎么定位到那 5 页"，之后每周都在真实页码上练；
- **给顺序**：先资产、再负债、再利润、再现金、最后估值——每一步都用同一家公司串起来；
- **给判断**：不止讲"这是什么"，更讲"这个数字不对劲时意味着什么"，第 9 周有完整的红旗清单；
- **给图**：所有涉及坐标、比例、结构的图都是**脚本生成的 PNG**（`figures/` 里保留生图脚本，想改就改）。

## 📖 怎么用这套教程

```
financial-report-study/（仓库根）
├── learning-guide/   ← 教程正文（你正在看的）
├── figures/          ← 所有配图的生图脚本 + 生成好的图片
├── data/             ← 已核实的真实财报数据（JSON）与提取规范
├── scripts/          ← 检查工具（LaTeX 规范、课程一致性）
└── CURRICULUM.md     ← 课程总纲与写作说明书（读者可略过）
```

1. **按顺序读，别跳。** 每周都依赖前面：没学会恒等式，后面看负债会一头雾水。
2. **边读边开年报。** 每章都有 `> 🔍 **翻到年报：**` 提示，告诉你现在该看哪一页；
3. **每章做「✍️ 想一想」**。思考题只需要动脑，答案就附在题目后面，先自己想再看；
4. **看图不爽？** 改 `figures/gen_*.py` 里的数字重新运行即可。

> 🖼️ 关于图片：所有涉及精确坐标的图都是**脚本生成的 PNG**（在 `figures/out/` 里）。
> 想调整任何一张图，改 `figures/` 里对应脚本重新运行即可。

## ✅ 学完你会得到什么

- 一套**可复用的年报扫读流程**：拿到任何一家 A 股/港股公司，10 分钟定位到关键数字，1 小时判断生意好坏；
- **看懂三张表**：知道每一行在说什么、哪几行最容易出问题、去哪里找附注验证；
- **识别风险**：商誉减值、应收账款暴增、合同负债异动、经营现金流与利润背离——20 条红旗清单；
- **会估值**：PE/PB 的正确用法与陷阱，DCF 的三步做法与敏感性分析；
- **一份自己写的分析报告**：以伊利 2024 年报为对象的完整示范，含估值区间。

## 📌 关于数字

- 教程里的伊利数字**全部来自 2024 年年度报告原文**，页码标注在每章末尾的「📎 数据出处」；
- 港股对照公司（蒙牛乳业）以「人民币千元」列示，教程中已统一换算成「元」再换算成「亿元」；
- **示意数字**（教学用的假设数字、假设股价）一律显式标注"示意"，不与真实数据混用；
- 年报里没有股价数据，教程中出现的股价**全部是假设价**，请自己查最新报价。
