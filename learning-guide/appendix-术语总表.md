## B.1 报表与基本概念

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 财务报表 | financial statements | 公司定期交出的"体检报告"，核心是三张表 |
| 合并报表 | consolidated statements | 把母公司和它控制的子公司当成一家来记的账 |
| 母公司报表 | parent company statements | 只记母公司自己那一层的账，不合并子公司 |
| 资产负债表 | balance sheet / statement of financial position | 某一天的快照：家底（资产）与钱的来源（负债 + 权益） |
| 利润表 | income statement / statement of profit or loss | 一段时间的录像：从收入一路减到净利润 |
| 现金流量表 | cash flow statement | 只认钱的录像：经营、投资、筹资三类 |
| 所有者权益变动表 | statement of changes in equity | 股东那份"家底"这一年怎么变的 |
| 附注 | notes to the financial statements | 报表数字背后的解释，年报里篇幅最大 |
| 会计政策 | accounting policies | 公司记账选用的规则（如折旧年限） |
| 会计估计 | accounting estimates | 需要人为判断的数字（如坏账比例） |
| 权责发生制 | accrual basis | 事情发生就记账，钱到没到账另说 |
| 收付实现制 | cash basis | 只认钱的实际进出 |
| 会计恒等式 | accounting equation | 资产 = 负债 + 所有者权益，永远成立 |
| 复式记账 | double-entry bookkeeping | 每一笔交易至少动两个格子 |
| 审计意见 | audit opinion | 会计师对报表"是否真实公允"的结论 |
| 关键审计事项 | key audit matters | 审计师认为最需要向投资者交代的事 |

## B.2 资产负债表——资产端

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 流动资产 | current assets | 一年内能变成现金的资产 |
| 非流动资产 | non-current assets | 一年以上才能变现的资产 |
| 货币资金 | cash and cash equivalents | 库存现金 + 银行存款，但**不等于能随便花** |
| 交易性金融资产 | financial assets at fair value through P&L | 买来短期赚差价的理财、股票 |
| 应收票据 | notes receivable | 客户给的、未来可收款的票据 |
| 应收账款 | accounts receivable / trade receivables | 赊账卖货还没收回来的钱 |
| 预付款项 | prepayments | 先付钱、后收货 |
| 其他应收款 | other receivables | 杂项应收，常是关联方占款的重灾区 |
| 存货 | inventory / inventories | 原材料、在产品、产成品 |
| 合同资产 | contract assets | 已完工但还没到收款节点的权利 |
| 长期股权投资 | long-term equity investments | 对联营、合营企业的投资 |
| 固定资产 | fixed assets / property, plant and equipment | 厂房、机器、设备，按净值记 |
| 在建工程 | construction in progress | 还没盖完、没投入使用的资产 |
| 使用权资产 | right-of-use assets | 租来的东西，按"未来要付的租金"记成资产 |
| 无形资产 | intangible assets | 专利、商标、土地使用权、软件 |
| 商誉 | goodwill | 收购时多付的那部分钱，只在并购中产生 |
| 递延所得税资产 | deferred tax assets | 现在多交、以后能少交的税 |
| 资产减值 | asset impairment | 资产不值账上那个价了，把差额记成损失 |

## B.3 资产负债表——负债与权益端

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 流动负债 | current liabilities | 一年内要还的债 |
| 非流动负债 | non-current liabilities | 一年以上才还的债 |
| 短期借款 | short-term borrowings | 一年内要还的银行贷款 |
| 应付票据 | notes payable | 开给供应商的票据 |
| 应付账款 | accounts payable / trade payables | 欠供应商的货款，**不用付利息** |
| 合同负债 | contract liabilities | 先收了钱、还欠客户货（旧准则叫"预收款项"） |
| 应付职工薪酬 | employee benefits payable | 还没发的工资奖金 |
| 应交税费 | taxes payable | 还没交的税 |
| 一年内到期的非流动负债 | non-current liabilities due within one year | 长期借款里明年要还的那部分 |
| 长期借款 | long-term borrowings | 一年以上才还的银行贷款 |
| 应付债券 | bonds payable | 公司发的债 |
| 租赁负债 | lease liabilities | 未来要付的租金现值 |
| 递延收益 | deferred income | 先收到、以后分期确认的收益（多为政府补助） |
| 有息负债 | interest-bearing debt | 要付利息的负债：借款 + 债券 + 租赁负债 |
| 经营性负债 | operating liabilities | 占用上下游的钱：应付、合同负债、应付薪酬 |
| 实收资本（股本） | share capital | 股东按面值投入的部分 |
| 资本公积 | capital reserve | 股东溢价投入、但不进利润的部分 |
| 库存股 | treasury shares | 公司自己买回来的股票，冲减权益 |
| 留存收益 | retained earnings | 历年赚下、没分掉的钱 |
| 盈余公积 | surplus reserve | 法定从利润里提的"公积金" |
| 其他综合收益 | other comprehensive income (OCI) | 还没进利润的"浮盈浮亏" |
| 归母权益 | equity attributable to owners of the parent | 真正属于上市公司股东的净资产 |
| 少数股东权益 | non-controlling interests | 子公司里不属于上市公司的那些份额 |

## B.4 利润表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 营业总收入 | total operating revenue | 营业收入 + 利息收入等（金融机构较多） |
| 营业收入 | revenue | 卖东西收到的（应计的）钱 |
| 营业成本 | cost of sales / cost of revenue | 直接为生产商品花的钱 |
| 毛利 | gross profit | 营业收入 - 营业成本 |
| 税金及附加 | taxes and surcharges | 消费税、城建税等 |
| 销售费用 | selling expenses | 广告、渠道、销售人员 |
| 管理费用 | administrative expenses | 总部、行政、管理人员 |
| 研发费用 | R&D expenses | 研究开发花的钱（费用化部分） |
| 财务费用 | finance expenses | 利息支出 - 利息收入 ± 汇兑损益 |
| 其他收益 | other income | 主要是政府补助 |
| 投资收益 | investment income | 处置股权、联营企业分来的利润 |
| 公允价值变动收益 | fair value changes | 持有的金融资产市价变动 |
| 信用减值损失 | credit impairment loss | 应收账款等收不回来的估计损失 |
| 资产减值损失 | asset impairment loss | 存货、固定资产、商誉等减值 |
| 营业利润 | operating profit | 主业 + 杂项之后的利润 |
| 营业外收入/支出 | non-operating income/expenses | 与主业无关的收支 |
| 利润总额 | profit before tax | 交所得税之前的利润 |
| 所得税费用 | income tax expense | 当期 + 递延所得税 |
| 净利润 | net profit | 利润总额 - 所得税 |
| 归母净利润 | net profit attributable to owners of the parent | 净利润里属于上市公司股东的那部分 |
| 少数股东损益 | non-controlling interests (P&L) | 净利润里属于子公司少数股东的那部分 |
| 非经常性损益 | non-recurring gains and losses | 一次性的、不代表持续经营能力的损益 |
| 扣非净利润 | net profit excluding non-recurring items | 归母净利润 - 非经常性损益（税后） |
| 基本每股收益 | basic EPS | 归母净利润 ÷ 加权平均股数 |

## B.5 现金流量表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 经营活动现金流净额 | net cash from operating activities | 主业真正收回来的现金净额 |
| 销售商品收到的现金 | cash received from sales | 收现能力的直接证据 |
| 投资活动现金流净额 | net cash used in investing activities | 买卖资产、理财的净流出/流入 |
| 购建长期资产支付的现金 | capital expenditure (capex) | 买设备、盖厂房花的钱 |
| 筹资活动现金流净额 | net cash from financing activities | 借还钱、分红、回购的净额 |
| 折旧与摊销 | depreciation and amortization (D&A) | 资产逐年变旧的代价，**不花现金** |
| 间接法 | indirect method | 从净利润倒推经营现金流的编表方法 |
| 营运资本变动 | changes in working capital | 存货、应收、应付的增减对现金的影响 |
| 自由现金流 | free cash flow (FCF) | 经营现金流 - 资本开支，公司能自由支配的钱 |

## B.6 比率

| 中文 | 英文 | 公式（人话版） |
|---|---|---|
| 毛利率 | gross margin | （收入 - 成本）÷ 收入 |
| 净利率 | net margin | 归母净利润 ÷ 收入 |
| 费用率 | expense ratio | 某项费用 ÷ 收入 |
| 收现比 | cash-to-revenue ratio | 销售收到的现金 ÷ 营业收入（>1 说明回款好） |
| 净现比 | OCF-to-net-profit ratio | 经营现金流 ÷ 净利润（长期应接近或大于 1） |
| 资产负债率 | debt-to-asset ratio | 负债合计 ÷ 资产总计 |
| 流动比率 | current ratio | 流动资产 ÷ 流动负债（>1 更安全） |
| 速动比率 | quick ratio | （流动资产 - 存货）÷ 流动负债 |
| 净有息负债 | net interest-bearing debt | 有息负债 - 类现金（为负说明钱多过债） |
| 存货周转率 | inventory turnover | 营业成本 ÷ 平均存货 |
| 应收账款周转天数 | days sales outstanding (DSO) | 365 ÷（收入 ÷ 平均应收账款） |
| 应付账款周转天数 | days payable outstanding (DPO) | 365 ÷（成本 ÷ 平均应付账款） |
| 现金转换周期 | cash conversion cycle (CCC) | 存货天数 + 应收天数 - 应付天数 |
| 总资产周转率 | asset turnover | 收入 ÷ 平均总资产 |
| 净资产收益率 | return on equity (ROE) | 归母净利润 ÷ 平均归母权益 |
| 权益乘数 | equity multiplier | 总资产 ÷ 归母权益（杠杆倍数） |
| 有效税率 | effective tax rate | 所得税费用 ÷ 利润总额 |
| 每股净资产 | book value per share (BVPS) | 归母权益 ÷ 总股本 |

## B.7 估值

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 内在价值 | intrinsic value | 公司未来能产生的现金折算到今天的总和 |
| 市值 | market capitalization | 股价 $\times$ 总股本 |
| 市盈率 | price-to-earnings ratio (PE) | 股价 ÷ 每股收益，或市值 ÷ 净利润 |
| 静态市盈率 | trailing PE (static) | 用上一个完整年度的净利润算 |
| 滚动市盈率 | TTM PE | 用最近四个季度净利润算 |
| 市净率 | price-to-book ratio (PB) | 股价 ÷ 每股净资产 |
| 股息率 | dividend yield | 每股分红 ÷ 股价 |
| 复利 | compound interest | 利滚利：$FV = PV \times (1+r)^n$ |
| 72 法则 | rule of 72 | 翻倍年数 $\approx$ 72 ÷ 年化收益率（%） |
| 贴现 | discounting | 复利的反运算：$PV = \dfrac{FV}{(1+r)^n}$ |
| 折现率 | discount rate | 把未来现金折算成今天的"利率" |
| 终值 | terminal value | 预测期之后所有现金流的价值 |
| 永续增长率 | perpetual growth rate (g) | 假设公司永远以 g 增长 |
| 敏感性分析 | sensitivity analysis | 换几个假设，看结论变多少 |
| 安全边际 | margin of safety | 买价明显低于估值的那个差额 |

## B.8 风险与红旗

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 关联交易 | related-party transactions | 和"自己人"做生意，最容易做手脚 |
| 商誉减值 | goodwill impairment | 并购标的没达预期，多付的钱要认亏 |
| 表外负债 | off-balance-sheet liabilities | 报表上看不见的债务（担保、明股实债） |
| 明股实债 | disguised debt | 名义上是股权、实质上是借款 |
| 大存大贷 | large deposits with large borrowings | 账上钱很多却还在大量借钱，典型异常 |
| 存贷双高 | high cash and high debt | 同上，另一种说法 |
| 应收账款激增 | receivables surge | 收入靠赊账堆出来，回款存疑 |
| 存货异常 | inventory anomaly | 存货增速远超收入，可能卖不动 |
| 审计意见非标 | modified audit opinion | 保留意见/无法表示意见，直接亮红灯 |
| 非经常性损益占比高 | high share of non-recurring items | 利润靠卖资产、补贴撑起来 |
| 经营现金流长期低于净利润 | OCF persistently below net profit | 赚的是"纸面利润" |

## B.9 三个最容易混的词

| 容易混的 | 区别 |
|---|---|
| 净利润 vs 归母净利润 | 前者含少数股东那份，后者只算上市公司股东那份 |
| 营业收入 vs 营业总收入 | 后者多了利息收入、已赚保费等（伊利多 3.86 亿元利息收入） |
| 毛利 vs 净利 | 毛利只减了成本；净利把费用、税、减值全减完了 |
| 利润 vs 现金流 | 利润按权责发生制记账；现金流只认钱的实际进出 |
| 商誉 vs 无形资产 | 商誉只在并购中产生，不能单独出售；无形资产可以 |
