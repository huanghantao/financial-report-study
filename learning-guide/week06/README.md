# 第 6 周导读：利润表 I——从收入到营业利润

**本周定位：** 前五周我们把资产负债表从资产端翻到负债和权益端，等于把一家公司的"家底"摸了一遍。从这一周起，我们把镜头从"有什么"转到"赚多少"——开始读利润表。本周只读完利润表的**上半场**：从营业总收入 1,157.80 亿元，一路减到营业利润 101.82 亿元。下半场（营业外收支、所得税、少数股东、归母净利润的含水量）留给第 7 周。这一周结束时，你会第一次遇到本书那条最重要的洞见：**伊利 2024 年报表上写着"利润大跌"，但主业其实在变好。**

## 学完你会得到什么

1. **能独立读完一张 A 股利润表的上半场**，并且知道哪几行值得停下来、哪几行可以扫过去。伊利这 24 行里，真正"动了"的只有 6 行。
2. **能算并解释四个核心比率**：毛利率（33.88%）、销售费用率（19.05%）、三费费用率（23.67%）、收现比（1.132）。每个比率都能说出"它由什么决定、变了说明什么"。
3. **能识破三个最常见的读数错误**：把营业总收入当营业收入、把毛利率上升当利润上升、把费用额下降当降本成功。
4. **能自己做一次"剔除一次性项目"的调整**，并且知道这个调整的边界在哪里（什么能加回、什么不能）。
5. **拿到一张五问清单**：收入、毛利率、费用率、减值与投资收益、所得税与少数股东——看到异常，知道该翻哪一页。

## 本周术语表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 利润表 | income statement / statement of profit or loss | 记录一段时期内收入、费用、利润的表；港股叫"损益表" |
| 营业总收入 | total operating revenue | 营业收入 + 利息收入等金融类收入；伊利 1,157.80 亿元 |
| 营业收入 | revenue | 卖商品/服务收到的（不含税）钱；伊利 1,153.93 亿元 |
| 营业总成本 | total operating cost | 营业成本 + 税金 + 销售 + 管理 + 研发 + 财务费用；伊利 1,037.57 亿元 |
| 营业成本 | cost of sales | 做出产品的直接花费：材料、人工、制造费用、运费 |
| 毛利 | gross profit | 营业收入 - 营业成本；伊利 390.94 亿元（自己算，报表无此行） |
| 毛利率 | gross margin | 毛利 ÷ 营业收入；伊利 33.88% |
| 销售费用 | selling expenses | 广告、促销、销售人员薪酬、仓储；伊利 219.82 亿元 |
| 管理费用 | administrative expenses | 总部薪酬、折旧、咨询审计；伊利 44.65 亿元 |
| 研发费用 | R&D expenses | 研发人员薪酬、试验设计费；伊利 8.70 亿元，全部费用化 |
| 财务费用 | finance expenses | 利息支出 - 利息收入 + 汇兑 + 手续费；伊利 -5.92 亿元 |
| 费用率 | expense ratio | 某项费用 ÷ 营业收入；跨年比较必须用比率，不能只用金额 |
| 营业利润 | operating profit | 收入减成本费用、加减杂项之后的利润；伊利 101.82 亿元 |
| 利润总额 | profit before tax | 营业利润 + 营业外收入 - 营业外支出；伊利 101.27 亿元 |
| 归母净利润 | net profit attributable to owners of the parent | 净利润里属于母公司股东的部分；伊利 84.53 亿元 |
| 控制权转移 | transfer of control | 客户能主导商品使用并获取几乎全部经济利益；收入确认的唯一标准 |
| 合同负债 | contract liabilities | 已收钱、未交货的义务；伊利 120.73 亿元 |
| 收现比 | cash-to-revenue ratio | 销售商品收到的现金 ÷ 营业收入；伊利 1.132 |
| 增值税 | value-added tax (VAT) | 价外税，利润表不含、现金流量表含；乳制品主要按 13% |
| 资产减值损失 | asset impairment loss | 认定资产不值账面价，一次性扣减利润、不花现金；伊利 46.76 亿元 |
| 信用减值损失 | credit impairment loss | 应收款、保理等金融资产的坏账准备；伊利 5.55 亿元 |
| 有效税率 | effective tax rate | 所得税 ÷ 利润总额；伊利 16.42% |
| 一次性项目 | one-off items | 今年有、明年不一定有的收支；分析时要单独标出 |

## 常见问题

> **Q：为什么伊利有两个"利息收入"，一个 3.86 亿元、一个 24.55 亿元？**
> A：不是同一个东西。3.86 亿元在"营业总收入"里，是旗下财务公司放贷收的利息，属于**收入**；24.55 亿元在"财务费用"明细里，是公司自己存款收的利息，属于**费用的减项**。前者是"做生意赚的"，后者是"存钱赚的"。第 26 章有对照表。

> **Q：毛利率上升了，是不是说明伊利变强了？**
> A：一半对。毛利率升 1.30 个百分点是真的，但拆开看，约 1.1 个点来自原奶降价（行业周期，会反转），只有约 0.2 个点来自产品结构改善（管理层功劳，可持续）。**而且毛利额其实降了 18.75 亿元**——比率升、总额降，两件事同时成立。第 28 章有完整拆分。

> **Q：把减值加回去算利润，是不是在自欺欺人？**
> A：不是，但有边界。"加回"的正确含义是把"过去决策的代价"（比如当年收购澳优付多了钱）从"今年经营的成绩"里剥离，而不是否认这笔损失存在。所以要标口径：会计口径 101.82 亿元、只加回商誉减值 132.57 亿元、加回全部减值 154.13 亿元。三个都报，看方向是否一致。第 30 章详述。

> **Q：为什么收入降 8.24%，归母净利润却降 18.94%？**
> A：三件事叠加：① 销售费用只降 2.61%，费用率升 1.10 个点，多花 12.71 亿元；② 资产减值从 15.26 亿元增到 46.76 亿元，多扣 31.50 亿元；③ 有效税率从 12.26% 升到 16.42%，又多扣约 4.2 亿元。投资收益 +24.17 亿元部分对冲了这些。第 30 章的逐行表能一行一行对上。

> **Q：伊利和蒙牛，谁更强？**
> A：看哪把尺子。毛利率蒙牛更高（39.57% vs 33.88%），净利率伊利高得多（7.33% vs 0.12%）。差在销售费用率：蒙牛 26.04%，伊利 19.05%。高毛利要靠高投入维持，最后落到净利上，伊利赢了。第 28 章有对照图。
