# 第 4 周导读：资产负债表 II——资产的质量（下）

**本周定位：** 上周我们把伊利 1,537.18 亿元资产的"上半截"翻完了——货币资金、应收、存货，都是**一年之内能变成现金**的东西。本周接着往下半截走：厂房设备、在建工程、无形资产、商誉。这四类资产占伊利总资产的 **29.0%**，却贡献了 2024 年 **52.31 亿元**的减值，是把 84.53 亿元归母净利润压到 -18.94% 的那只手。下周我们去资产负债表的右边，看那 967.10 亿元负债。

本周有一条贯穿始终的暗线：**这四类资产，都有一个"账面数字不等于真实价值"的裂缝。** 折旧年限是估计，在建工程转固时点是判断，研发资本化比例是选择，商誉减值时点是管理层的决定。四周下来你会慢慢明白一件事：**资产端最容易出问题的地方，不是"有没有这个资产"，而是"这个数字是怎么算出来的"。**

## 学完你会得到什么

1. **能读懂固定资产附注的四段表**：原值、累计折旧、减值准备、账面价值，一眼看出这家公司的设备"用了几年、还剩多少"；能分辨"固定资产折旧 38.18 亿元"和"现金流量表折旧 40.56 亿元"的口径差别。
2. **能判断一家公司在扩张还是在收缩**：算出"资本开支 ÷ 折旧"这个比值，再用收入增速做交叉验证，三分钟给出方向性结论。
3. **能看懂研发支出的会计选择**：知道费用化和资本化对利润、资产、现金流各自的影晌，能在一分钟内判断一家公司的研发政策是保守还是激进。
4. **能拆开商誉这本账**：从"原值 → 减值准备 → 净额"三行数字里，看出这笔商誉是哪次收购留下的、减了多少、还剩多少、集中在谁身上。
5. **能对一次大额减值做出独立判断**：不再被"利润跌了 19%"或"现金流涨了 19%"单方面带走，能用"减值前利润""扣非净利润""剩余商誉占净资产"三个数把事件还原清楚。

## 本周术语表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 固定资产 | fixed assets / property, plant and equipment | 厂房、机器、设备，按**净值**（原值减累计折旧减减值）记 |
| 原值 | original cost / gross value | 当初买它花了多少钱，入账后基本不动 |
| 累计折旧 | accumulated depreciation | 从买来到今天，一共"用掉"了多少 |
| 净值 | net book value | 原值减累计折旧减减值准备，资产负债表上那个数 |
| 折旧 | depreciation | 把固定资产的成本按使用年限分摊到各年；**不花现金** |
| 折旧年限 | useful life | 公司自己估计的"能用几年"，**是估计不是事实** |
| 残值率 | residual value rate | 报废时预计还能卖回几个百分点，伊利多用 5% |
| 年限平均法 | straight-line method | 最常用的折旧方法：把应折旧总额平均摊到每一年 |
| 会计估计变更 | change in accounting estimate | 改折旧年限、改坏账比例这类调整，合法但要披露 |
| 在建工程 | construction in progress | 已经花钱、但还不能干活的资产；**不计提折旧** |
| 转固 | transfer to fixed assets | 工程完工后从"在建工程"转入"固定资产"，从次月起计提折旧 |
| 资本开支 | capital expenditure (capex) | 现金流量表上"购建长期资产支付的现金"；是**现金口径** |
| 再投资强度 | reinvestment intensity | 资本开支 ÷ 折旧；大于 1 扩张、约等于 1 维持、小于 1 收缩 |
| 无形资产 | intangible assets | 土地、商标、软件、专利这类没有实体但能带来收入的资产 |
| 摊销 | amortization | 无形资产的"折旧"；使用寿命不确定的（如商标权）不摊销 |
| 使用寿命不确定 | indefinite useful life | 没有到期日的资产，不摊销，但每年必须做减值测试 |
| 研发费用化 | R&D expensed | 研发支出全部计入当期费用，利润当期就承担 |
| 研发资本化 | R&D capitalized | 符合条件的开发支出记为资产，未来几年摊销 |
| 开发支出 | development expenditure | 资本化研发的"中转站"，资产负债表上单独一行 |
| 商誉 | goodwill | 收购价减被收购方可辨认净资产公允价值；**只在并购中产生** |
| 可辨认净资产公允价值 | fair value of identifiable net assets | 把标的的资产逐项按市价评估后，减去负债 |
| 资产组 | asset group / cash-generating unit | 能独立产生现金流的"最小业务单元"，商誉要分摊到它上面 |
| 减值测试 | impairment test | 每年比对"账面价值"与"可收回金额"，账面高了就计提减值 |
| 可收回金额 | recoverable amount | 未来现金流折现值，与"公允价值减处置费用"两者取高 |
| 资产减值损失 | asset impairment loss | 存货、固定资产、商誉等资产不值钱了的损失，进利润表 |
| 信用减值损失 | credit impairment loss | 应收款收不回来的坏账损失，和资产减值损失是**两行** |
| 洗大澡 | big bath | 在业绩差的年份一次性把坏消息提完，为次年做铺垫 |
| 扣非净利润 | net profit excluding non-recurring items | 剔掉卖资产、政府补助这类一次性损益后的利润 |

> 📌 **最容易混的三对词：** ①**折旧 vs 摊销**——同一件事，固定资产叫折旧、无形资产叫摊销；②**资本开支 vs 在建工程**——前者是现金口径（今年付了多少钱），后者是账面状态（还没干完的工程值多少）；③**资产减值损失 vs 信用减值损失**——前者是"东西不值钱了"，后者是"钱收不回来了"，报表上是两行，别合并。

## 常见问题

> **Q：为什么伊利的折旧在利润表里扣了一次，在现金流量表里又要加回来？这不是重复计算吗？**
>
> A：不是重复，是两张表在回答不同的问题。利润表问的是"这一年赚了多少"——买机器的钱要在使用它的十年里分摊，所以每年扣一笔折旧。现金流量表问的是"这一年收进来多少现金"——买机器的钱在买的那年就付掉了，之后每年不再有现金流出，所以要把折旧加回来。**同一笔钱，两张表里方向相反，因为一张算"应计"、一张算"实收"。**

> **Q：伊利 capex 39.78 亿元低于折旧 40.56 亿元，是不是说明它在衰退？**
>
> A：不能直接这么说。它只说明"今年投的钱不够补上旧资产的消耗"。要看原因：如果是产能已经够用、需求见顶，这是理性的收手；如果是没钱投或不敢投，才是问题。判断的关键是配合收入增速——伊利 2024 年收入降 8.24%，属于"收入在降 + 投资在降"，这个组合需要警惕；但如果一家公司收入在涨、capex 在降，那反而是效率提升的好事。

> **Q：商誉减值 30.75 亿元，为什么经营现金流还有 217.40 亿元，还同比增长 18.86%？**
>
> A：因为减值不花一分钱现金。商誉本来就不是"钱"，它只是收购时记在账上的一个数字。把它减掉，只是承认"这个数字虚高了"，银行账户一分没动。所以在编制现金流量表时，这 52.31 亿元减值会被作为"不涉及现金的费用"加回。**减值影响利润，不影响现金**——这是本周最该带走的一句话。

> **Q：伊利研发费用率只有 0.75%，是不是说明它不重视研发？**
>
> A：不是。乳业的研发费用率普遍在 0.5%~2% 之间，0.75% 属于行业正常水平。这门生意的核心竞争力在奶源、渠道、品牌，研发的作用是"让产品不落后"，不是"领先一个代际"。**跨行业比研发费用率没有意义，只能和同行比。**

> **Q：怎么快速判断一家公司的商誉风险大不大？**
>
> A：两个比例。①**商誉 ÷ 归母净资产**：告诉你"最坏情况有多坏"（伊利 23.37 ÷ 531.80 = 4.4%，可承受）；②**最大一笔商誉 ÷ 商誉总额**：告诉你"风险集中在哪"（伊利澳优 21.55 ÷ 23.37 = 92.2%，高度集中）。两个都看，才知道风险的大小和形状。
