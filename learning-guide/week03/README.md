# 第 3 周导读：资产负债表 I——资产的质量（上）

**本周定位：** 前两周我们学会了"资产负债表左右必须相等"（第 7 章）和"利润是算出来的、现金是收到的"（第 9 章）。从这一周开始，我们把镜头对准资产负债表的**左半边**——资产，而且只问一个问题：**这些资产，到底值多少？**

这一周要拆的是流动资产里的"三件套"：钱、应收、存货。它们看起来最像现金，实际上也最容易踩坑。下周（第 16~20 章）再处理非流动资产——固定、在建、无形、商誉。

**本周最重要的一个案例：** 伊利 2024 年货币资金少了 179.68 亿，看起来像"没钱了"，实际上它手里的类现金反而多了 42 亿。这个反差，是整本书里最好的一个"别只看一行"的教材。

## 学完你会得到什么

1. **能自己给资产分类。** 拿到任何一张资产负债表，30 秒内分清流动资产和非流动资产，并能说清"为什么这一项在那一栏"。
2. **能看穿"货币资金"这个科目。** 知道钱可能藏在"其他流动资产""其他非流动资产""一年内到期的非流动资产"三个地方，也知道受限资金会让"账上的钱"打折。
3. **能算三个周转指标。** 应收账款周转天数、存货周转率、存货周转天数，并且知道用期末还是平均、分子用收入还是成本。
4. **能判断存货变动的好坏。** 不再看到"存货下降"就高兴，而是先把它和收入增速放在一起比。
5. **能独立写出一份三句话的资产结论。** 一句讲结构、一句讲质量、一句讲风险——这是本周的毕业作业。

## 本周术语表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 流动资产 | current assets | 一年内（或一个营业周期内）能变成现金的资产 |
| 非流动资产 | non-current assets | 一年以上才能变成现金的资产 |
| 流动性 | liquidity | 一项资产变成现金的速度，以及变现时会不会打折 |
| 营业周期 | operating cycle | 从买原料到收回货款走完一圈的时间 |
| 流动负债 | current liabilities | 一年内要还的负债 |
| 流动比率 | current ratio | 流动资产 ÷ 流动负债，衡量短期覆盖 |
| 速动比率 | quick ratio | （流动资产 - 存货）÷ 流动负债，更严的覆盖指标 |
| 货币资金 | cash and bank balances | 库存现金 + 银行存款 + 其他货币资金 |
| 受限资金 | restricted cash | 账上有、但被保证金/质押/准备金锁住、不能自由动用的钱 |
| 大额存单 | large-denomination certificate of deposit | 起点较高、利率高于活期的存款凭证；期限超一年要记非流动资产 |
| 应收账款 | accounts receivable / trade receivables | 已交货已开票、客户还没付的钱 |
| 应收票据 | notes receivable | 客户给的票据，银行承兑的几乎无坏账风险，还可背书转让 |
| 账龄 | aging | 应收账款形成至今的时间长度，越长越可能收不回 |
| 坏账准备 | allowance for doubtful accounts | 预先认掉的、预计收不回的应收账款 |
| 信用减值损失 | credit impairment loss | 利润表上因信用风险计提的损失（应收、保理、担保、小贷等） |
| 存货 | inventory | 原材料、半成品、库存商品、包装材料等 |
| 存货跌价准备 | inventory write-down | 存货账面价值高于可变现净值时计提的损失 |
| 可变现净值 | net realizable value | 估计售价减去进一步加工成本和销售费用后的金额 |
| 存货周转率 | inventory turnover | 营业成本 ÷ 存货，一年转几圈 |
| 应收账款周转天数 | days sales outstanding (DSO) | 应收账款 ÷ 营业收入 $\times$ 365，多少天收回钱 |
| 商誉 | goodwill | 收购价高于被收购方可辨认净资产公允价值的差额 |
| 商誉减值 | goodwill impairment | 商誉对应的未来收益撑不住时，把账面价值往下调 |
| 递延所得税资产 | deferred tax assets | 现在多交了税、未来可以少交，兑现前提是"未来有利润" |

## 常见问题

> **Q：只有伊利一家公司，没有对照，会不会看不出好坏？**
>
> A：本周有几处用"行业常识"作对照（比如应收 9 天 vs 工程机械 100~200 天），但没有做严格的同业对比。原因是：蒙牛的数据我们只收了几个关键项（`data/mengniu2024.json`），做完整的资产结构对比口径不齐。**真正的同业对比放在第 9 周第 45 章**，那时候两家的数据都齐了，会做一张四维仪表盘。本周先把"怎么看一家"练熟，比"同时看两家"更重要。

> **Q：第 12 章说类现金 652.07 亿，第 12.5 节又说 728.54 亿，到底用哪个？**
>
> A：**主口径用 652.07 亿**（货币资金 + 其他流动资产里的存单 + 其他非流动资产里的存单），因为这三个数是"期限明确、性质清楚"的存款。728.54 亿是在此基础上再加"一年内到期的大额存单 76.47 亿"——它是辅助口径，用来交叉验证方向。**两个口径都在说"钱变多了"，这才是一个可靠的结论。** 如果两个口径打架，就要在文章里明写差异来源。

> **Q：为什么伊利流动比率只有 0.74，书里却说它没有偿债危机？**
>
> A：先说一个**容易被传错的事实**：伊利流动负债 899.25 亿元里，**硬债（短期借款 363.55 + 短期应付债券 100.24 + 一年内到期 92.30 = 556.08 亿元）占了 61.8%**，经营性占款只有 341.57 亿元（38.0%）。所以「负债大多是占款、不用怕」这个流行说法，在这份年报上是不成立的——第 11 章有一张完整的拆解表。
>
> 真正让它安全的，是另外两条：① 流动资产被"藏"了一部分（118.26 亿存单记在其他流动资产里，279.77 亿记在其他非流动资产里，都不算进流动比率）；② 经营现金流每年两百多亿正流入，2024 年是 217.40 亿元，覆盖利息 11.9 倍。**完整的偿债分析在第 5 周第 23、25 章**，本周只是埋个伏笔。

> **Q：这一周要动手算什么吗？**
>
> A：要。至少亲手算三遍：① 666.19 + 870.99 是不是等于 1,537.18；② 254.04 + 118.26 + 279.77 是不是等于 652.07；③ 28.78 ÷ 1,153.93 $\times$ 365 是不是约 9.1。**这三个验算做完，你对"数字之间会互相印证"这件事才有了体感。** 不需要写代码，用计算器就行。

> **Q：看完这一周，我能判断一家公司"资产好不好"了吗？**
>
> A：能判断大半，但还差两块：**固定资产的折旧假设**（第 4 周）和**负债端的结构**（第 5 周）。资产质量从来不是单独存在的——一家公司资产很漂亮，但如果全靠借债撑起来，那是另一回事。所以本周的定位是"资产质量（上）"，下周补完下册，第 5 周再看右边那一栏。
