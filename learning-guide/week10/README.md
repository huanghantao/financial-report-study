# 第 10 周导读：估值与结业——给公司标一个价

**本周定位：** 九周下来，你已经能把一份年报拆开、量一遍、再装回去。你知道伊利的毛利率在逆势上升、知道减值吃掉了 52.31 亿元利润、知道经营现金流反而涨了 18.86%——**你能回答"这家公司过去一年干得怎么样"，但还回答不了"它值多少钱"。**

这两件事之间隔着一整个"未来"。本周要做的，就是把"过去的事实"换算成"未来的价格"：先讲清价格与价值的区别（第 46 章），再拿出三把尺子——市盈率（第 47 章）、市净率与 ROE（第 48 章）、现金流折现（第 49 章）——最后用它们给伊利叠出一个区间，并写成一份完整的分析报告（第 50 章）。

本周也是全书的收口。第 50 章会把十周的十个动作装成一条流水线，兑现 CURRICULUM 里那条"全书最重要的洞见"：**伊利 2024 年是"账面利润下滑、主业在改善"，而估值的关键变量只有两个——减值是否出清、收入能否恢复。**

## 学完你会得到什么

1. **能分清"价格"和"价值"**：知道市场先生的报价为什么不能当价值用，知道安全边际是"为算错留的余地"，而不是"打折买便宜货"。
2. **能当场拆穿一个 PE**：看到任何 PE，先问"静态还是 TTM""归母还是扣非"，并且能自己算出三种口径下的三个 PE（伊利：17.2 / 21.1 / 29.8 倍）。
3. **能用 PB-ROE 判断"贵得有没有道理"**：会算隐含要求回报率（ROE ÷ PB），会读 PB-ROE 象限，知道 PB 适合银行、不适合软件。
4. **能独立算一遍 DCF**：会用复利公式和 72 法则，会算终值，会做"增速 $\times$ 折现率"的敏感性表，并且接受"输出是区间"。
5. **能写出一份 3,000 字的分析报告**：按"生意 → 能力 → 资产 → 负债 → 现金流 → 红旗 → 估值 → 结论"八段走，每段都有数字支撑。
6. **能回答那个终极问题**："什么价格我才动手，什么情况下我认错。"

## 本周术语表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 内在价值 | intrinsic value | 一家公司未来能产生的现金折回今天的总和，是一个区间而不是一个点 |
| 市场价格 | market price | 此刻买卖双方成交的数字，每秒在变，由情绪和资金共同决定 |
| 市场先生 | Mr. Market | 格雷厄姆的比喻：一个情绪不稳、每天来报价的合伙人，你可以选择不跟他交易 |
| 安全边际 | margin of safety | 只在价格显著低于估算价值时买入，为"算错"预留的空间 |
| 市盈率 | price-to-earnings ratio (PE) | 股价 ÷ 每股收益，本质是"回本年数"，倒数是收益率 |
| 静态 PE | static PE | 分母用上一个完整会计年度的利润 |
| 滚动 PE | trailing PE / TTM | 分母用最近四个季度的利润之和 |
| 预期 PE | forward PE | 分母用预测的下一年利润（是假设，不是事实） |
| 扣非市盈率 | PE on deducted earnings | 分母用扣非归母净利润，最保守的 PE 口径 |
| 盈利收益率 | earnings yield | PE 的倒数，1 ÷ PE，表示"如果利润全部分给你"的年化回报 |
| PEG | price/earnings-to-growth | PE ÷ 净利润增速，给成长股用的补丁，负增长时失效 |
| 市净率 | price-to-book ratio (PB) | 股价 ÷ 每股净资产，表示"为账面 1 元付几元钱" |
| 净资产收益率 | return on equity (ROE) | 归母净利润 ÷ 归母净资产，衡量股东资金的赚钱效率 |
| 隐含要求回报率 | implied required return | ROE ÷ PB 的反推值，表示"这个价格隐含的回报要求" |
| 破净 | below book value | PB 小于 1，股价低于账面净资产，可能是机会也可能是陷阱 |
| 复利 | compounding | 利息也生利息，$FV = PV \times (1+r)^n$ |
| 终值 | future value (FV) | 一笔钱按某收益率滚 n 年后的金额 |
| 72 法则 | rule of 72 | 翻倍年数约等于 72 ÷ 年化收益率（%） |
| 贴现 | discounting | 复利的逆运算，把未来的钱折回今天，$PV = FV \div (1+r)^n$ |
| 折现率 | discount rate | 把未来现金流折回今天时要求的最低回报率 |
| 现金流折现 | discounted cash flow (DCF) | 把未来所有自由现金流折现加总，得到企业价值 |
| 终值（DCF） | terminal value (TV) | 明确预测期之后所有现金流的打包价值，$TV = FCF_{n+1} \div (r-g)$ |
| 永续增长率 | perpetual growth rate | 第 5 年之后现金流的长期增速，通常取 1%~3% |
| 敏感性分析 | sensitivity analysis | 改变一个或两个假设，看结果变化多大；DCF 必做 |
| 交叉验证 | cross validation | 用多种估值方法互相对照，看区间是否重叠 |
| 企业价值 | enterprise value (EV) | 整个公司的价值（含债权人部分）；减去净有息负债才是股东价值 |

## 常见问题

> **Q：这一周学了三种估值方法，到底该信哪一个？**
> A：都不该"单独信"。PE 反映市场愿意为利润付多少，PB 反映市场愿意为家底付多少，DCF 反映"如果我的假设成立，它值多少"。三者的作用不同：**PE、PB 帮你判断"相对贵不贵"，DCF 帮你判断"绝对上值多少"**。正确用法是三个都算，看区间是否重叠——重叠处才是"多个角度都说得通"的价格。第 50 章会把三个区间叠成一张图。

> **Q：DCF 算出来 26 到 54 元，差一倍，那算它有什么用？**
> A：用处恰恰在于"它告诉你差一倍"。**一个精确的 37 元是假象，一个诚实的 26~54 元是真相。** 更重要的是：DCF 会逼你把假设写下来（增速多少、折现率多少、永续增长多少），而一旦写下来，你就可以问自己"这组假设我信几分"。**能说清"我在什么假设下认为它值多少"的人，比能说出一个精确数字的人可靠得多。**

> **Q：为什么书里老说"假设股价 28 元"，不能直接告诉我现价吗？**
> A：不能，也不该。**第一，年报里没有股价**，本书的所有数字都必须能追溯到年报页码；**第二，股价每天都在变**，任何写进书里的"现价"第二天就过期；**第三，也是最重要的——本书教你的是算法，不是答案。** 给你一个价格，你只会得到一个结论；给你一套方法，你能算出所有公司的结论。你自己查价、自己代进去，那才是你的分析。

> **Q：伊利 2024 年利润跌了 18.94%，为什么第 50 章还说"主业在改善"？**
> A：因为利润里混着两股相反的力量。往下压的是 52.31 亿元减值（比 2023 年多提 35.45 亿元），往上托的是 24.42 亿元非经常性损益。把减值加回去，经营性利润是 154.13 亿元、同比 **+13.7%**；同时毛利率升 1.30 个百分点、经营现金流涨 18.86%、收现比升到 1.132——**三条独立证据都指向"主业没坏"**。但这句话有一个未验证的假设：**减值明年不会再来**。所以第 50 章的结论是"减值是否出清"和"收入能否恢复"这两个变量决定估值，而不是"伊利一定被低估"。

> **Q：学完这十周，我是不是就可以买股票了？**
> A：你有了"独立分析一家公司"的能力，但这不等于"每家公司都该由你分析"，更不等于"分析对了就一定能赚钱"。**估值解决"值多少钱"，不解决"明天涨不涨"**；市场先生的情绪可以持续很久，价格可以在价值下方待三年。这本书教你的，是**在动手之前知道自己买的是什么、可能错在哪、什么价格才值得出手**——剩下的，是仓位、耐心和运气。
