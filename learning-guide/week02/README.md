# 第 2 周导读：会计的语言——一张表怎么记下整家公司

**本周定位：** 上周你把一份 270 页的年报从头翻到尾，知道了三张表在哪一页、附注是什么，
但那些数字对你还是"天书"。这一周我们不上来就背科目，而是先回答一个更根本的问题：
**一家公司的全部生意，怎么能被几十行数字装进一张表里？**
答案是三条：一个恒等式、一条记账纪律、一个记账时点的选择。
把这三样弄懂，第 3 周开始拆资产、第 5 周拆负债、第 6 周拆利润表，你才不会变成"背科目"。

## 学完你会得到什么

1. **能独立读懂任何一张资产负债表的两栏。** 看到左边一项资产，你会条件反射地问：
   这是谁的钱买的？右边一栏能给出答案。
2. **能对任何一笔业务说出"它动了哪两个格子"。** 借钱、还钱、赊销、预收、分红、回购，
   六类交易一套就套进去，不用背分录。
3. **能做三表勾稽，并且知道对不上时该查什么。** 三个等式、四种常见错误、三个合法例外，
   你已经有一张排查清单。
4. **看懂"利润 $\neq$ 现金"这件事的机制，而不是只记住结论。** 折旧摊销、减值、营运资本变动，
   这三块怎么把 84.64 亿元变成 217.40 亿元。
5. **拿到一个新数字，会先问"它明年还在不在"。** 这是本周最重要的一种职业习惯：
   区分一次性因素和可持续因素。

## 本周术语表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 资产负债表 | balance sheet / statement of financial position | 某一天的"家底快照"：有什么、欠什么、剩下什么 |
| 利润表 | income statement / statement of profit or loss | 一段时期的"赚钱记录"：收入减费用等于利润 |
| 现金流量表 | cash flow statement | 一段时期的"现金流水账"：经营、投资、筹资三类 |
| 资产 | assets | 公司拥有或控制、能带来经济利益的资源 |
| 负债 | liabilities | 过去交易形成、将来要用钱或货去还的义务 |
| 所有者权益 | owners' equity / shareholders' equity | 资产减负债的差额，也叫"净资产" |
| 剩余权益 | residual equity | 所有者权益的另一个名字，强调"拿剩下的" |
| 归母权益 | equity attributable to owners of the parent | 属于母公司股东的那部分权益，不含少数股东 |
| 少数股东权益 | non-controlling interests | 子公司里不属于母公司的权益 |
| 会计恒等式 | accounting equation | 资产 = 负债 + 所有者权益 |
| 复式记账 | double-entry bookkeeping | 每笔交易至少动两个格子的记账方法 |
| 试算平衡 | trial balance | 检验借方合计是否等于贷方合计 |
| 权责发生制 | accrual basis | 权利/义务发生时确认，不看钱何时进出 |
| 收付实现制 | cash basis | 钱收到/付出时才确认 |
| 应收账款 | accounts receivable / trade receivables | 已经交货、还没收到的钱 |
| 合同负债 | contract liabilities | 已经收钱、还没交货的义务（旧称"预收款项"） |
| 折旧 | depreciation | 固定资产的价值逐年分摊到费用 |
| 摊销 | amortization | 无形资产、长期待摊费用的逐年分摊 |
| 减值 | impairment | 资产不值原来那么多钱了，账上砍下来 |
| 营运资本 | working capital | 存货 + 应收 - 应付，衡量日常经营占用的钱 |
| 净现比 | operating cash flow to net profit | 经营现金流 ÷ 净利润，衡量利润的"含金量" |
| 未分配利润 | retained earnings | 历年赚的钱扣掉分红后留在公司的部分 |
| 现金及现金等价物 | cash and cash equivalents | 可随时动用、三个月内到期的现金类资产 |
| 溯源 / 勾稽 | cross-check / reconciliation | 用两个独立来源的数字互相验证 |
| 流量 | flow | 一段时期内的发生额（利润、现金流） |
| 存量 | stock | 某一时点的余额（资产、负债、权益） |

## 常见问题

> **Q：这一周一个公式接一个公式，我需要背下来吗？**
> A：只需要背两条：$A = L + E$，和"每笔交易动两个格子"。
> 其余的（六类交易、三个等式、净现比）都是这两条的推论，用的时候现推就行。
> 背公式的人会在第 5 周忘记，会推的人能用到第 50 章。

> **Q：我不打算做会计，学复式记账是不是浪费时间？**
> A：这一周教的不是"怎么做账"，是"怎么看懂别人做的账"。
> 你要掌握的能力是：看到一笔业务，能猜出它会动哪两个科目、会让哪张表变好看。
> 这个能力在识别造假时是决定性的——因为**造假的人必须让两个格子同时动**，
> 你只要盯住"另一格在哪"，就能找到破绽。

> **Q：伊利 2024 年净利润下降 17.7%，是不是公司变差了？**
> A：本周只能给你半个答案。净利润下滑，同时经营现金流增长 18.9%，
> 说明"利润在降、收钱在增"——这不是典型的恶化形态。
> 真正的原因要拆到收入端（第 26~30 章）和减值端（第 32 章）才看得清。
> 本周你能确认的是：**打折的是利润，不是现金。**

> **Q：我要不要自己也拉一张 Excel 表跟着算一遍？**
> A：建议做，但只做三件事：① 抄 page_087~088 的六个大数，验算恒等式；
> ② 抄 page_095 的三行，验算现金勾稽；③ 抄 page_088 的未分配利润两列，
> 加上 page_092 的归母净利润和 page_045 的分红，验算未分配利润的滚动。
> 三张表，九个数字，半小时。**亲手算过一次，比读十遍都管用。**

> **Q：本周为什么反复强调"示意数字"？**
> A：因为奶茶店那套数字是虚构的，只用来演示结构。
> 一旦你把"20 万、40 万"当成真实数据，或者把伊利的数字和奶茶店的混在一起算，
> 后面几周会一路错下去。**本教程的规矩是：凡是虚构的，必须写明"示意数字"；
> 凡是真实的，必须给页码。**
