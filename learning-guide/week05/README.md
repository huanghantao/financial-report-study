# 第 5 周导读：资产负债表 III——负债、权益与偿债能力

**本周定位：** 前四周我们把资产负债表的左边翻完了——从货币资金、应收、存货，到厂房、在建工程、无形资产、商誉。那 1,537.18 亿元资产，讲的是"这家公司有什么"。本周翻到右边：**967.10 亿元负债、570.08 亿元所有者权益**，讲的是"这些东西是谁出钱买的"。

右边比左边更难读，因为它更容易被"负债率"这一个数字糊弄过去。教科书写着"负债率 60% 以上要警惕"，于是很多人看到伊利 62.91% 就转身走了——**他们错过了一家账上净现金 46.50 亿元、每年经营现金流 217.40 亿元的公司。**

本周的核心只有一句话：**负债要先分类，再看覆盖，最后看期限。** 三步走完，62.91% 这个数字才会有意义。

## 学完你会得到什么

1. **能在三分钟内把任何一家公司的负债拆成两堆。** 知道要抄哪四个数、要点开哪两个附注（其他流动负债、一年内到期的非流动负债），能抓出藏在"其他"里的短期融资券——伊利那 100.24 亿元就藏在里面。
2. **能算清一家公司真正有多少现金。** 不再只看"货币资金"那一行，会去"其他流动资产""其他非流动资产"的附注里翻大额存单。伊利这一步能多找出 398.03 亿元，净有息负债的符号会因此由正转负。
3. **能判断"先收钱"是好是坏。** 掌握三个验证动作（看应收、看待转销项税、看下一期收入），知道合同负债大增既可能是渠道看好，也可能是压货，并且知道哪一种能靠年报判断、哪一种只能等下一期。
4. **能看懂权益那六个格子。** 分得清归母权益和少数股东权益，知道未分配利润是"历年攒的"不是"当年不分红"，知道库存股和其他综合收益为什么是负数。
5. **能对两家同行业公司做一次规范的偿债对照。** 会用"偿债体检四步法"，并且知道跨市场对照要先对齐口径（千元/元、利息放在哪一类现金流）。

## 本周术语表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 负债 | liabilities | 欠别人的钱或义务，按一年内到期与否分流动/非流动 |
| 有息负债 | interest-bearing debt | 借来的、要按利率付息的钱：借款、债券、租赁负债 |
| 经营性负债 | operating liabilities | 经营中自然产生的欠款，通常不计息：应付账款、合同负债、应付职工薪酬 |
| 短期借款 | short-term borrowings | 一年内到期的银行借款 |
| 应付债券 | bonds payable | 公司发行的、期限一年以上的债券 |
| 短期应付债券 | short-term bonds payable | 超短期融资券等，伊利 100.24 亿元列在"其他流动负债"里 |
| 一年内到期的非流动负债 | non-current liabilities due within one year | 长期借款、债券中一年内要还的部分，从非流动挪到流动 |
| 租赁负债 | lease liabilities | 未来租金的折现值，本质是"借钱租东西"，要付利息 |
| 合同负债 | contract liabilities | 已收钱、还没交货的义务；"欠货"不是"欠钱" |
| 预收款项 | advances from customers | 旧准则科目；伊利 2023 年那 26.47 亿元是**股权转让款** |
| 待转销项税 | deferred output VAT | 预收货款对应的增值税，纳税义务未发生时先挂在这里 |
| 净有息负债 | net interest-bearing debt | 有息负债减类现金；为负叫"净现金" |
| 类现金 | cash and deposits | 货币资金 + 大额存单 + 定期存款，分散在三个科目里 |
| 期限错配 | maturity mismatch | 用短期负债支撑长期资产，靠滚动续借维持 |
| 借新还旧 | refinancing / rollover | 旧债到期发新债接上；伊利一年滚动约 2,200 亿元 |
| 利息覆盖倍数 | interest coverage ratio | 经营现金流 ÷ 利息支出，衡量付息能力 |
| EBITDA | earnings before interest, tax, depreciation and amortization | 息税折旧摊销前利润，粗略衡量"赚钱能力" |
| 所有者权益 | owners' equity | 资产减负债，属于股东的那部分 |
| 归母权益 | equity attributable to owners of the parent | 权益中属于上市公司股东的部分 |
| 少数股东权益 | non-controlling interests | 子公司中不属于上市公司的净资产份额 |
| 实收资本（股本） | share capital | 股东按面值投入的本金 |
| 资本公积 | capital reserve | 股东投入超过面值的部分（溢价） |
| 库存股 | treasury stock | 公司回购自己的股票，从未分配权益中扣减 |
| 其他综合收益 | other comprehensive income (OCI) | 不进利润表、但改变权益的浮盈浮亏 |
| 盈余公积 | surplus reserve | 按规定从净利润中强制提取的留存 |
| 未分配利润 | retained earnings | 历年净利润中未分配给股东的部分 |
| 每股净资产 | book value per share | 归母权益 ÷ 总股本，伊利 8.35 元 |
| 资产负债率 | debt ratio | 总负债 ÷ 总资产 |
| 流动比率 | current ratio | 流动资产 ÷ 流动负债 |
| 速动比率 | quick ratio | （流动资产 - 存货）÷ 流动负债 |

## 常见问题

> **Q：资产负债率 62.91%，到底算不算高？**
> A：单看数字偏高（教科书常说的安全线是 50%）。但伊利的答案是"高，但撑得住"：它的有息负债 605.58 亿元被 652.07 亿元类现金覆盖，净有息负债是 -46.50 亿元；经营现金流 217.40 亿元，是利息支出的 11.9 倍。**高杠杆 + 厚现金 + 强现金流，是三种不同的东西，必须一起看。**

> **Q：合同负债涨 38.8%，收入却跌 8.24%，是不是在压货？**
> A：目前证据偏向"不是恶意压货"，但没到能下结论的程度。支持"不是"的有三条：应收账款同步收缩（-6.7%）、待转销项税同步增长（+23.7%）、蒙牛合同负债也在涨（+24.3%，同期收入 -10.1%）。但**唯一能判决的证据是 2025 年一季报的收入**——如果收入继续跌、合同负债转头向下，那就是透支。这道题本书没法替你答完，得你自己去查。

> **Q：净有息负债是负数，是不是就绝对安全？**
> A：不是。净有息负债是**存量**概念（总共够不够），不回答**期限**问题（到期那天够不够）。伊利 556.08 亿元一年内到期，货币资金只有 254.04 亿元，缺口 302.04 亿元，靠一年滚动 2,200 亿元借款维持。**总量安全、期限紧，这两句话同时成立。**

> **Q：为什么第 11 章说流动比率 0.74 不是危机，第 23 章又说是缺口？**
> A：两件事不矛盾。0.74 是"报表口径"的覆盖率；缺口 302.04 亿元是"硬债对可动用现金"的覆盖率。第 23 章把 279.77 亿元藏在非流动资产里的大额存单加回来后，流动比率变成 1.05；再把 120.73 亿元合同负债（欠货不欠钱）从分母剔掉，变成 1.22。**0.74 是分类造成的紧张，302.04 亿元是真实的期限压力。**

> **Q：未分配利润 322.29 亿元，是不是说明公司很吝啬、不分红？**
> A：恰恰相反。伊利 2024 年度分红预案是 77.26 亿元，占当年归母净利润的 91.40%。322.29 亿元是**过去二十多年**一年一年累下来的，不是某一年不分红攒的。"留存大"和"分红率高"完全可以同时成立。

> **Q：为什么要用蒙牛做对照，不用 A 股的其他乳企？**
> A：三个原因：它是伊利最直接的竞争对手；规模量级接近（总资产 1,062.93 亿元对 1,537.18 亿元）；它是港股，报表格式不同，正好练一次"跨市场对照"。**跨市场对照会逼你注意口径差异**（千元/元、利息放在经营还是筹资），这个能力比多背一个指标有用。
