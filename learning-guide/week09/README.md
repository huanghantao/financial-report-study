# 第 9 周导读：三表勾稽、比率与红旗清单

**本周定位：** 前八周我们建了四套工具：三张表怎么看（第 2~5 周）、利润怎么拆（第 6~7 周）、现金流怎么验（第 8 周）、红旗怎么找（还没系统讲）。但它们一直是**分散使用**的——看资产时只看资产，看利润时只看利润，看现金流时只看现金流。

本周做三件事：① 把三张表**焊在一起**，用「一笔交易走三张表」的推演，看同一件事怎么在利润表、资产负债表、现金流量表上留下三个不同时点的脚印；② 把 ROE **拆成三块**（净利率、周转率、权益乘数），第一次能回答「伊利到底靠什么赚钱」；③ 把「一家公司要不要垫钱做生意」量化成一个数——现金转换周期，伊利只有 **2.6 天**。

最后两章是全书的**质检环节**：第 44 章给你 20 条红旗（提问清单，不是定罪清单），第 45 章把伊利和蒙牛放进同一张仪表盘，用同一套工具扫一遍。

**本周也是全书「最重要那条洞见」的第三次收口。** 第 6 周说「毛利率逆势涨 1.30 个点」，第 7 周说「营业利润 -14.2% 里有 35.45 亿是多提的减值」，第 8 周说「经营现金流 +18.86%」。本周的杜邦分解给出第四条证据链：**ROE 下滑的 63% 来自净利率，而净利率下滑的主因是 35.45 亿元额外减值，不是毛利率恶化——毛利率反而涨了 1.30 个百分点。** 一个只读 ROE 的人看到「15.81%，跌了 4.39 点」，一个会拆杜邦的人看到「毛利率涨、减值砸、现金流涨」——**两种人买的是同一只股票，判断完全相反。**

## 学完你会得到什么

1. **能在一小时内把一家陌生公司的三张表验一遍**：第 41 章那张八条清单，从「资产 = 负债 + 权益」到「附注金额 = 主表金额」，任何一条不平都知道该怀疑什么。
2. **能亲手做杜邦分解，并指出 ROE 变化的主因**：拿到任何一家公司，先算三块，再用连环替代法拆出「各贡献几个百分点」，最后判断这个变化是可持续的还是一次性的。
3. **会算 CCC，并用它判断「增长要不要靠融资」**：存货、应收、应付三个天数，两个口径（期末/平均）都懂，知道为什么同一家公司能算出 1.6 天和 2.6 天。
4. **手握 20 条红旗清单，知道每条去哪一页验证**：不会再「凭感觉觉得这家公司有问题」，也不会「因为勾稽平了就以为万事大吉」。
5. **能做同业对比，且知道什么时候不能比**：口径怎么对齐、比率什么时候失真（净利接近零时净现比无意义）、「数据不足」和「未命中」的区别。

## 本周术语表

| 中文 | 英文 | 一句话解释 |
|---|---|---|
| 勾稽 | articulation / cross-checking | 不同报表、不同附注之间的数字必须能互相印证 |
| 净资产收益率 | return on equity (ROE) | 归母净利润 ÷ 归母净资产，衡量股东投的钱一年赚回多少 |
| 杜邦分解 | DuPont analysis | 把 ROE 拆成净利率 $\times$ 资产周转率 $\times$ 权益乘数 |
| 净利率 | net margin | 净利润 ÷ 营业收入，卖 100 元最后落下多少 |
| 资产周转率 | asset turnover | 营业收入 ÷ 总资产，一块钱资产一年做出几块钱收入 |
| 权益乘数 | equity multiplier | 总资产 ÷ 归母权益，杠杆倍数 |
| 连环替代法 | sequential substitution | 一次只换一个因子，看结果变化多少，用来做归因 |
| 存货周转天数 | days inventory outstanding (DIO) | 平均存货 ÷ 营业成本 $\times$ 365 |
| 应收账款周转天数 | days sales outstanding (DSO) | 平均应收账款 ÷ 营业收入 $\times$ 365 |
| 应付账款周转天数 | days payable outstanding (DPO) | 平均应付账款 ÷ 营业成本 $\times$ 365 |
| 现金转换周期 | cash conversion cycle (CCC) | 存货天数 + 应收天数 - 应付天数；越短越好，为负说明用别人的钱做生意 |
| 营运资金需求 | working capital requirement | 收入 ÷ 365 $\times$ CCC，做生意要自己垫的钱 |
| 大存大贷 | high cash and high debt | 账上钱多、同时大量借钱；可能是资金管理，也可能是存贷双高造假 |
| 存贷双高 | inflated cash with matching debt | 借真钱造「假现金」，让虚增的货币资金看起来是真的 |
| 关键审计事项 | key audit matter (KAM) | 审计师主动披露的「本次审计最重要的事项」 |
| 非经常性损益 | non-recurring gains and losses | 不常发生、不代表持续经营能力的损益 |
| 扣非净利润 | net profit excluding non-recurring items | 归母净利润扣掉非经常性损益，看主业赚多少 |
| 表外担保 | off-balance-sheet guarantee | 不进资产负债表、只在或有事项里披露的担保 |
| 明股实债 | disguised debt as equity | 名义上是股权投资，实际有回购或固定收益条款 |
| 商誉减值 | goodwill impairment | 被收购业务不值原价时，把差额从利润里扣掉 |

## 常见问题

> **Q：三个勾稽等式都平了，是不是就能说明报表没问题？**
> A：不能。等式平只说明「算术对了」，不说明「业务是真的」。第 41 章举过例子：虚构 10 亿元收入 + 虚构 10 亿元应收，三个等式全平，但报表是假的。真正的检验是第 44 章那 20 条红旗，尤其是「利润和现金流是否匹配」和「附注和主表是否一致」。

> **Q：伊利 ROE 从 20.20% 掉到 15.81%，是不是竞争力下降了？**
> A：不完全是。杜邦分解显示，下滑的 63% 来自净利率，而净利率下滑的主因是 35.45 亿元的额外减值——**毛利率反而涨了 1.30 个百分点**。减值是会计判断，不是经营恶化。如果 2025 年减值回到正常水平，ROE 有修复空间（粗算约 21%）。但这只是「如果」，不是预测。

> **Q：CCC 只有 2.6 天，是不是算错了？**
> A：没算错。存货 55.6 天（乳业有生产周期和铺货需求）+ 应收 9.4 天（经销商先款后货）- 应付 62.5 天（对上游有议价权）= 2.6 天。这是快消品 + 强势渠道的典型特征。第 43 章还讲了另一个口径（期末余额）算出 1.6 天，两个数都对，只是算法不同。

> **Q：伊利命中了 5 条红旗，还能买吗？**
> A：这个问题问错了。「命中红旗」不等于「有问题」。20 条里大部分抓的是「常见现象」，需要人工判断。伊利命中的 5 条（商誉、大存大贷、非经常、Q4 亏损、关联采购）逐条翻附注后都能解释。**正确的问题是：这 5 条的解释站不站得住？** 第 44 章给了逐条的证据强度评级。

> **Q：蒙牛净利只有 1.05 亿元，是不是快倒闭了？**
> A：不是。它的经营现金流 83.32 亿元、自由现金流 48.57 亿元、货币资金 173.39 亿元，短期偿债和经营都没问题。利润被打穿是因为 55.56 亿元减值（贝拉米商誉 11.55 亿 + 商标 34.90 亿 + 存货 9.11 亿）——**这些减值是账面调整，没有现金流出。** 「利润被打穿」和「公司要倒闭」是两件事。
